# מאגר הידע — איך זה עובד ואיך מוסיפים תוכן

## המבנה

| קובץ | תפקיד |
|---|---|
| `corpus.js` | **המאגר עצמו** — פסקאות עובדתיות שהסוכן שולף מהן |
| `retrieve.js` | מנוע האחזור — בוחר את 2-3 הפסקאות הרלוונטיות להודעה הנוכחית |
| `knowledge.js` | תקציר מובנה (חוק, שלבים, יתרונות) שנכנס לפרומפט הניתוח |
| `faq.js` | תשובות מוכנות — רשת ביטחון בלבד, כשאין התאמה במאגר |

## איך הסוכן משיב

```
הודעת לקוח
   ↓
retrieve.js  →  בוחר פסקאות רלוונטיות מ-corpus.js
   ↓
ai/brain.js  →  Claude מנסח תשובה *במילים שלו* על בסיס הפסקאות
   ↓
guardrails   →  חוסם מחירים והבטחות
```

אם אין מפתח API, המערכת שולפת את הפסקה הרלוונטית ומגישה אותה כמעט כמו שהיא.
זה נכון עובדתית אבל נשמע "בלוקי" — שם נמצא ההבדל בין מצב תסריט למצב AI.

## להוסיף מאמר חדש

הוסיפו אובייקט למערך `PASSAGES` בקובץ `corpus.js`:

```js
{
  id: 'unique_id',                      // מזהה ייחודי
  topics: ['מילת מפתח', 'עוד אחת'],      // מילים שסביר שהלקוח יכתוב
  src: 'D',                             // מפתח מתוך SOURCES
  text: `הטקסט העובדתי.
שורות קצרות. עובדות, לא שיווק.`,
}
```

**כללים:**
- פסקה אחת = רעיון אחד. עדיף 6 פסקאות קצרות על אחת ארוכה.
- `topics` הן הכי חשובות — כתבו איך *הלקוח* ישאל, לא איך עורך דין מנסח.
- אל תכניסו שכר טרחה. אגרות רשמיות (אפוסטיל, קונסוליה, B1) מותרות.
- אחרי הוספה: `npm test` ואז `npm run sim` כדי לבדוק שהאחזור תופס.

## המושג המרכזי במאגר

**שנת העלייה קובעת את המסלול.** זה הבסיס לכל שיחת זכאות:

| שנת יציאה | קבוצה | מגבלת דורות | שבועה | B1 |
|---|---|---|---|---|
| 1950-52, 1965-67, 1988+ | לא נשללה | **אין** | לא | לא |
| שנות ה-30, 1948-49 | נשללה | נכדים | כן | כן |
| 1957-64 | ויתור כפוי | נכדים | כן | כן |
| בסרביה, לידה 1918-40 | בסרביה | נינים | כן | כן |

הסיווג מתבצע אוטומטית ב-`sales/leadProfile.js` → `deriveGroup()`.

## מה עוד כדאי להוסיף

התוכן הנוכחי מכסה את מה שנשלף מהאתר שלך ומהמסמך ששלחת. נושאים שהוזכרו
בכותרות אך אין להם עדיין פסקה מלאה:

- אזרחות מולדובית כמסלול חלופי
- דרכון רומני לסטודנטים / לאנשי עסקים
- השקעות נדל"ן ברומניה
- דרכון רומני מול פורטוגלי — השוואה
- תיקון 2025 לחוק האזרחות (הפרטים המלאים)
- קביעת תורים לקונסוליה — נהלים מעודכנים

הדרך המהירה להוסיף: שלח לי את המאמר (הדבקה או קובץ), ואני מוסיף פסקאות
עם `topics` מתאימים ומריץ את הבדיקות.
