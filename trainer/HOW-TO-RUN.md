# הרצת סוכן האימון — הוראות

הסוכן מדבר עם **הבוט האמיתי שלך** (אותו קוד, אותו מאגר ידע, אותם guardrails),
מנהל מולו שיחות בתור לקוחות שונים, ומחזיר דוח עם ציון ונקודות לשיפור.

הכל מקומי. שום דבר לא מגיע לוואטסאפ.

---

## הפעם הראשונה — התקנה

```
cd "C:\claude folder\whatsapp-passport-bot\trainer"
pip install -r requirements.txt
```

אם `pip` לא מוכר:
```
python -m pip install -r requirements.txt
```

זה מתקין שלוש חבילות: `anthropic`, `requests`, `python-dotenv`.

**המפתח** — לא צריך להעתיק אותו. המערכת קוראת את `ANTHROPIC_API_KEY`
מקובץ ה-`.env` של הבוט (רמה אחת מעלה), אותו כבר הגדרת.

---

## הרצה

צריך **שני חלונות** של Command Prompt.

**חלון 1 — הבוט:**
```
cd "C:\claude folder\whatsapp-passport-bot"
npm run sim
```
השאר אותו פתוח.

⚠️ **אם שיניתי קוד מאז ההרצה הקודמת — חובה לסגור ולהפעיל מחדש את החלון הזה.**
Node טוען את הקבצים פעם אחת בהפעלה, אז שרת שרץ מאתמול מריץ את הקוד של אתמול.

איך לוודא שהקוד המעודכן רץ — חפש בפלט של `npm run sim` את השורה:
```
Rules:  הסדרה: 1950-1952, 1964-1967, 1988+ · סעיף 10: כל השאר · סעיף 11: בסרביה/בוקובינה/הרצה
```
אם השורה הזו לא מופיעה, או שהתאריכים שונים — השרת ישן. סגור אותו (Ctrl+C) והפעל שוב.

**חלון 2 — המאמן:**
```
cd "C:\claude folder\whatsapp-passport-bot\trainer"
python run_training.py --bot real
```

זה מריץ את כל שמונה הפרסונות ברצף ומייצר דוח מסכם.

### הרצות ממוקדות

```
python run_training.py --list                                  רשימת הפרסונות
python run_training.py --bot real --persona avi_impatient      פרסונה אחת
python run_training.py --bot real --persona shira_price_shopper --runs 3
python run_training.py --bot real --random --runs 5
python run_training.py --bot real --turns 6                    שיחות קצרות יותר
python run_training.py --bot real --dry-run --persona avi_impatient   בדיקת צנרת, בלי עלות
```

## מה הדוח בודק

שלושת הפרמטרים המרכזיים:

1. **שפה מקצועית** — האם הבוט שמר על טון מכבד, גם מול לקוח תוקפני
2. **הנעה לפעולה** — האם הצליח להוביל לשיחת ייעוץ ולאסוף פרטים
3. **הזיות** — האם אמר משהו שאינו נתמך ב-`knowledge/facts.md`

ובנוסף: טיפול בהתנגדויות, הסמכת ליד, בהירות, גבולות, ואמפתיה.

**`knowledge/facts.md` הוא מקור האמת.** מילאתי אותו מהמאגר של הבוט — שלוש
הקבוצות, לוחות הזמנים, האגרות המאושרות, פטורי B1, האמירות האסורות והיתרונות
שלך. אם הבוט ינקוב בשכר טרחה או ימציא מספר, המעריך יתפוס אותו.

אם אתה משנה את `src/kb/corpus.js` — עדכן גם את `facts.md`, אחרת בדיקת ההזיות
תסמן עובדות נכונות כשגויות.

## מחזור העבודה

```
1. npm run sim                              (חלון 1)
2. python run_training.py --bot real        (חלון 2)
3. קרא את הדוח המסכם
4. תקן:
     ניסוח לא טוב      →  src/ai/examples.js
     עובדה חסרה        →  src/kb/corpus.js  (+ facts.md)
     התנגדות לא נתפסה  →  src/sales/objections.js
5. הפעל מחדש את הסימולטור והרץ שוב
```

הציון אמור לעלות בין סבבים. כשהוא יציב ואתה מרוצה מהשיחות — זה הסימן
שאפשר להעלות לאוויר.

## עלות

כל שיחה מלאה עולה בסביבות 10-30 אגורות (הסוכן, הבוט והמעריך ביחד).
סבב של שמונה פרסונות — בערך 1-3 ₪.

לבדיקת צנרת בלי עלות בכלל: הוסף `--dry-run`.

## תקלות נפוצות

**`No module named 'anthropic'`**
לא הותקנו החבילות. `pip install -r requirements.txt`

**`חסר ANTHROPIC_API_KEY`**
ודא שהשורה קיימת ב-`.env` של הבוט (רמה אחת מעלה) או של המאמן.

**`Connection refused` / `bot_error`**
הסימולטור לא רץ. פתח חלון נוסף והרץ `npm run sim`.

**כל התשובות מגיעות מהתסריט**
המאמן ידפיס `ℹ️ התשובה הזו הגיעה מהתסריט`. ודא ש-`AI_MODE=live` ב-`.env`
והפעל מחדש את הסימולטור.

**עברית הפוכה במסך**
זו רק תצוגת CMD. קרא את קובצי הדוח.
